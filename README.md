# Project Title: Android Labs

## Description
A collection of Android development labs focusing on fundamental concepts and hands-on exercises.

## Features
- Lab 1: Introduction to Android Studio and basic UI components.
- Lab 2: Implementing navigation and intents.
- Lab 3: Working with data storage and SQLite.

## Technologies Used
- **Language:** Java
- **Tools:** Android Studio

## Setup Instructions
1. Clone the repository: `git clone https://github.com/Sonu-praj/AndriodLabs.git`
2. Open the project in Android Studio.
3. Run the application on an emulator or physical device.
